# Wikely

Wikely est un projet personnel que j'ai développé afin de mettre en pratique mes compétences en **développement web** et en **utilisation d'API** à travers la création d'une application permettant de rechercher et d'explorer des informations provenant de Wikipédia.

L'application est réalisée en **HTML**, **CSS** et **JavaScript**, avec pour objectif principal de progresser en développement front-end, en manipulation de données provenant d'une API et en création d'une interface moderne et agréable.

## 📖 À propos du projet

Wikely est une application web permettant de **rechercher des informations sur différents sujets à partir de l'API Wikipédia**.

L'utilisateur peut effectuer une recherche et obtenir les informations correspondantes directement dans une interface dédiée, sans avoir besoin de naviguer directement sur Wikipédia.

Ce projet me permet de développer mes compétences en développement web, en manipulation d'API et en expérience utilisateur, tout en proposant une manière simple et moderne d'explorer des informations.

L'objectif n'est pas seulement de créer une application fonctionnelle, mais également de développer mes compétences en :

* HTML5
* CSS3
* JavaScript
* Utilisation d'API
* Manipulation de données JSON
* Requêtes HTTP
* Responsive Design
* UI / UX Design

## 🚀 Technologies utilisées

* 🌐 HTML
* 🎨 CSS
* ⚡ JavaScript
* 🔗 API Wikipédia

## 🎯 Objectifs

* Concevoir une application web de recherche d'informations de façon autonome
* Améliorer mes compétences en développement front-end ainsi qu'en conception d'interfaces (UI/UX)
* Apprendre à utiliser et exploiter une API externe
* Découvrir la manipulation de données JSON et les requêtes HTTP en JavaScript
* Réaliser un projet concret pouvant être enrichi sur mon GitHub
